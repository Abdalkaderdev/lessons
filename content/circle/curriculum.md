# The Circle

A small group of close friends — like family — learning AI together. Sessions happen in person, all of us in the same room at the same time.

## Goal

Make AI genuinely useful in each person's actual work. Not theory, not hype. By the end of each session, every person in the room should be able to walk out and use what they learned the same day.

## How sessions run

- One session at a time, everyone present
- Each module is built around a real task someone in the group already does
- We try every tool together — same prompt, same screen, compare results
- Homework is something each person applies to their own work that week

## Tools we'll use

- **Claude** (claude.ai) — primary assistant
- **ChatGPT** (chatgpt.com) — alternative for comparison
- Tool-specific picks added per module as needed

## What this is not

- Not a lecture series — every session ends with hands-on output
- Not generic "AI 101" — every example is tied to real work someone in the room does
